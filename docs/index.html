Blazingly Fast Startup.

Same intuitive syntax for HTTP requests. Zero Python runtime dependency. Instant ~2ms startup time.

Get Started
cargo install rusttp-cli
bash — rusttp
# Simple JSON POST request
$ rusttp POST https://httpbin.org/post name="Anilcan Kara" age:=28 Authorization:"Bearer token"

HTTP/1.1 200 OK
content-type: application/json
server: gunicorn/19.9.0

  "json": {
    "name": "Anilcan Kara",
    "age": 28

Designed for Modern Developers

⚡

~150x Faster Startup

Runs in ~2ms compared to Python-based HTTP clients. Built in pure Rust for minimum memory footprint.

🎨

Syntax Highlighting

Automatic syntax colorization for JSON, HTML, and XML responses with full terminal color support.

🔌

Offline Preview Mode

Use --offline to preview and inspect your HTTP requests before sending them over the wire.

📁

File & Multipart Uploads

Effortlessly upload images and files using the intuitive key@./path.jpg syntax.

🔐

Built-in Auth

Supports Basic authentication and Bearer tokens out of the box with the -a flag.

📦

Static Binaries

Zero dependencies. Download single static binaries for Windows, Linux, and macOS (Intel & Apple Silicon).
