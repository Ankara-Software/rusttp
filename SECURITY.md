# Security Policy

## Supported Versions

We release security patches for the latest release.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within rusttp, please **do not open a public GitHub issue**.

Instead, please report it privately to **anilcan@kara.dev**.
We will acknowledge receipt within 48 hours and provide an estimated fix timeline.
